# Distribution policy

BAY65 is an independent, source-only portfolio project. Original code is provided under the MIT licence. The public repository starts from a reviewed source snapshot, not the original personal development history.

The owner has confirmed rights to distribute the original source and branding. This is an owner statement, not independent legal or trademark clearance.

- Source builds and tests are documented in [CONTRIBUTING.md](CONTRIBUTING.md).
- No signed public APK is distributed at present. A future binary release requires verified provenance, signature and checksums, separate physical-device acceptance, and maintainer approval.
- Do not publish maintenance APKs, signing material, private settings, API keys, personal photos or identifiable transit screenshots.
- Review applicable [LTA data terms](DATA-ATTRIBUTION.md), [privacy](PRIVACY.md), and [third-party notices](THIRD-PARTY-NOTICES.md).
- Keep CI and security checks enabled and resolve findings before merging or distributing changes.

See [sharing](SHARING.md) and [validation](android/VALIDATION.md). Automated checks and owner acceptance are not a security certification.
